Modifier un texte ou un lien hypertexte dans une page HTML

Cette documentation explique comment retrouver un bouton, un texte ou un lien dans un fichier HTML, puis modifier soit le texte affiché, soit l’adresse du lien.

Règle simple : dans un lien HTML, le texte visible est entre > et </a>. L’adresse du lien est dans href="...".

1. Faire une copie du fichier

  1. Dupliquez le fichier HTML avant toute modification.
  2. Gardez une version originale, par exemple : page-originale.html.
  3. Travaillez sur une copie, par exemple : page-modifiee.html.

2. Ouvrir le fichier HTML

Ouvrez le fichier avec un éditeur de texte :

  • Bloc-notes sur Windows
  • TextEdit sur Mac en mode texte brut
  • Visual Studio Code, recommandé si disponible

3. Chercher un bouton, un texte ou un lien

Utilisez la fonction de recherche :

  • Sur Windows : Ctrl + F
  • Sur Mac : Cmd + F

Cas A — Chercher un texte précis

Si vous voulez modifier le texte visible hello@deskopolitan.com, cherchez directement :

hello@deskopolitan.com

Vous trouverez par exemple :

<a href="mailto:hello@deskopolitan.com?subject=Programme%20de%20parrainage%20-%20Deskopolitan">hello@deskopolitan.com</a>

Cas B — Chercher un bouton ou un lien

Pour trouver tous les liens ou boutons cliquables, cherchez :

<a href

Chaque résultat correspond généralement à un lien cliquable.

Cas C — Chercher un bouton avec un mot affiché

Si le bouton affiche par exemple Contactez-nous, cherchez :

Contactez-nous

Vous pouvez aussi chercher un mot plus court si vous n’êtes pas sûr du texte exact :

Contact

4. Modifier le texte affiché d’un lien

Exemple avant modification :

<a href="https://deskopolitan.com/wp-content/uploads/2025/01/DP-reglement_parrainage_2025-241230.pdf">règlement de parrainage disponible sur ce lien.</a>

Dans cet exemple, le texte affiché est :

règlement de parrainage disponible sur ce lien.

Vous pouvez le remplacer par :

consultez le règlement complet du programme de parrainage.

Résultat après modification :

<a href="https://deskopolitan.com/wp-content/uploads/2025/01/DP-reglement_parrainage_2025-241230.pdf">consultez le règlement complet du programme de parrainage.</a>
Ne modifiez pas l’adresse dans href="..." si vous voulez seulement changer le texte visible.

5. Modifier l’adresse du lien

Pour changer la destination du lien, il faut modifier uniquement ce qui se trouve dans href="...".

Exemple avant :

<a href="https://ancien-lien.com">Voir le règlement</a>

Exemple après :

<a href="https://nouveau-lien.com">Voir le règlement</a>

Ici, le texte affiché reste le même, mais le lien mène vers une nouvelle adresse.

6. Modifier un lien email

Un lien email commence souvent par mailto:.

Exemple actuel :

<a href="mailto:hello@deskopolitan.com?subject=Programme%20de%20parrainage%20-%20Deskopolitan">hello@deskopolitan.com</a>

Changer uniquement le texte affiché

<a href="mailto:hello@deskopolitan.com?subject=Programme%20de%20parrainage%20-%20Deskopolitan">contactez notre équipe</a>

Changer l’adresse email de destination

<a href="mailto:nouvelleadresse@deskopolitan.com?subject=Programme%20de%20parrainage%20-%20Deskopolitan">contactez notre équipe</a>
Pour un lien email, l’adresse réellement utilisée est celle après mailto:, pas forcément le texte visible.

7. Modifier un lien autour d’une image ou d’un bouton visuel

Certains liens ne contiennent pas de texte, mais une image.

Exemple :

<a href="https://www.instagram.com/deskopolitan/">
  <img alt="Instagram" src="image-instagram.png">
</a>

Dans ce cas :

  • Il n’y a pas de texte visible à modifier.
  • Pour changer la destination du clic, modifiez l’adresse dans href="...".
  • Pour modifier le nom descriptif de l’image, modifiez alt="Instagram".

8. Résumé rapide

Objectif Partie à modifier Exemple
Changer le texte visible Texte entre > et </a> >Nouveau texte</a>
Changer la destination du lien Adresse dans href="..." href="https://nouveau-lien.com"
Trouver tous les liens Recherche dans le fichier <a href
Trouver un texte précis Recherche du mot affiché règlement, Contact, hello@

9. Tester après modification

  1. Enregistrez le fichier HTML.
  2. Ouvrez-le dans un navigateur.
  3. Vérifiez que le texte affiché a bien changé.
  4. Cliquez sur le lien pour vérifier qu’il mène au bon endroit.
  5. Si le lien est un email, vérifiez qu’il ouvre bien le bon destinataire.

10. Checklist finale

  • J’ai fait une copie du fichier original.
  • J’ai cherché le texte ou le bouton avec Ctrl + F ou Cmd + F.
  • J’ai identifié le bon bloc <a href="...">...</a>.
  • J’ai modifié le texte visible seulement si besoin.
  • J’ai modifié le lien dans href="..." seulement si besoin.
  • J’ai testé le fichier dans un navigateur.
  • J’ai cliqué sur le lien pour vérifier qu’il fonctionne.
